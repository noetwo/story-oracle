# 故事神谕·精简版（Story Oracle Lite）

基于 [故事神谕（Story Oracle）](https://github.com/namelessone88/story-oracle) 1.89.0 精简的二创版本，原作者 namelessone88。

只保留两个用来规划剧情的功能：

- 💬 **普通聊天**：在独立窗口里就当前剧情提问，不碰主聊天。
- 🧭 **剧情参谋**：和参谋一起构思剧情走向，采用后悄悄引导主聊天。支持单拍方案和多拍的序列引导。

另外新增两件事：

1. **所有提示词都能在设置里改。** 普通聊天和参谋实际发给模型的每一段文字，都可以逐条修改、一键恢复默认，不用再改代码。
2. **序列引导的「贯穿设定」。** 给一整条序列写下幕后的既定事实，每一拍都会带着它注入主聊天，叙事模型就不会自己编出相互矛盾的解释。

---

## 和原版的关系

- **删掉的功能**：诊断（含自动诊断、变量编辑器、修改器）、世界书模式、校正（含选段校正、自动校正）、角色工坊、弧线（透明 / 盲盒）、数据库联动、插件接口（StoryOracleAPI，大纲版等插件依赖它）、更新检查。
- **共用数据**：精简版和原版用同一套设置和聊天数据，所以原版里的连接配置、补全预设挑选、参谋讨论记录、已采用的方案 / 序列，装上精简版后都还在。
- **不能同时启用**：两者界面元素一样，同时启用会冲突。精简版检测到原版在运行时，会弹出提示并停止加载。请在扩展管理里只启用其中一个。
- **切回原版**：精简版新写的数据（自定义提示词、贯穿设定）原版会直接忽略。另外，原版的弧线优先级高于序列和单拍，所以精简版每次全新采用方案或序列时，会顺手清掉这个聊天里原版留下的弧线数据，免得切回原版后旧弧线压过你的引导。

## 安装

1. 把整个 `story-oracle-lite` 文件夹放进酒馆的第三方扩展目录（与原版「故事神谕」放在同一处，通常是 `data/<用户名>/extensions/`）。
2. 在「扩展 → 管理扩展」里**停用原版「故事神谕」**，启用「故事神谕·精简版」，刷新页面。
3. 这个文件夹没有指向原版仓库的 git 远程，**不要点酒馆的「更新扩展」**；需要更新时直接替换文件。

## 使用

### 普通聊天

点输入框上方快捷回复栏里的「故事神谕」按钮（或魔杖菜单里的 🌙）打开窗口，直接提问。窗口读取角色卡、世界书、最近的对话记录和 MVU 变量（可在设置里调整），回答只留在神谕窗口里。

### 剧情参谋

点标题栏的 🧭 进入参谋模式，和参谋讨论剧情走向。

- **单拍方案**：参谋给出 1~3 个 `<StoryPlan>` 方案卡，点「开始引导」后，主聊天会被悄悄推向这个方向。
- **序列引导**：讨论的是一整段长线剧情时，参谋会排成一条 `<StorySequence>` 序列。采用后同一时间只有当前这一拍在引导主聊天，演完点「完成」换下一拍，换拍不花钱。
- **下一拍建议**：序列进行中，在主聊天最新回复下给出几条你接下来可以发的话（在「参谋设置」里开启）。
- 方案条上的 ✏️ 可以手改这一拍的内容（目标 / 切入 / 节奏），强度档可以随时切换。
- 一拍演完了没有由你自己判断，点「完成」换下一拍。
- 想先跑偏一阵再回来，点方案条上的「暂停」，主聊天就暂时不注入；点「继续」接着引导。

### 注入了什么

引导进行中，主聊天每次生成只多出一段，贴在玩家消息里（很多中转会把对话中间的 system 消息挪到最顶上，贴进玩家消息才稳）。只有主聊天的正文生成（发送、重新生成、换一条、继续）会带上它，其它插件的后台请求不会：

```
<剧情导向>
以下是{{user}}希望接下来的剧情走向，供你构思正文时参考：贯穿设定是整条剧情的背景与走向，眼下只推进当前这一拍，不要提前演后面的阶段；请用你自己的叙述自然地写出来，不要照抄、复述或提及这段内容。
【贯穿设定】
（总体走向 + 幕后事实）
【第 3/8 拍：拍标题】
目标：……
切入：……
节奏：……
</剧情导向>
```

单个方案没有贯穿设定和拍号，那两部分自动省略。外壳和「这一拍的内容」都在设置的「提示词 → 主聊天注入」里，可以改。

### 贯穿设定

多拍序列最常见的问题：某一拍只透露了一半真相，主聊天模型不知道后面的设定，就会自己编一个解释。比如你设定的是「家族实权在妻子手里，丈夫身体健康，只是推到台前的傀儡」，第三拍透露了「掌控人是妻子」，模型却写成了「丈夫卧病在床」。

贯穿设定就是用来解决这个问题的：

- 参谋输出序列时，会在 `title` 下面写一段 `canon:`，内容是讨论中定下来的隐藏真相（人物真实身份与状态、隐藏关系、谜底）。
- 序列卡上可以在采用前补写或修改；采用后，方案条拍列表的第一行「📌 贯穿设定」可以随时查看和编辑。
- 每一拍注入主聊天时，贯穿设定都在「剧情导向」里、这一拍的前面。你用 ✏️ 手改某一拍，也不会把它弄丢。
- 回参谋房修改序列时，参谋也看得到它；新提案里带了 `canon:` 就整段替换，不带就沿用原来的。
- 设定每一拍都会注入，太长会占用上下文。超过 1500 字时会提示，但不会截断。

### 切换模型

输入框上方有一条小栏，显示当前用的是哪个连接存档、哪个模型。点它会列出你存过的连接存档，点一下就切换，不用进设置；最下面的「管理连接…」直接打开设置的「连接」页。

连接存档在 设置 →「连接」页管理：填好端点、密钥、模型后起个名字点「存为新存档」。存档平时只占一行，显示当前在用的那个；点开列出全部存档，点哪个就用哪个，每行末尾可以删除。

### 设置

点 ⋯ → 设置打开，设置会铺满整个窗口，右上角 ✕ 回到聊天。顶部分成 5 页：

- **连接**：连接存档、连接方式（直连 / 酒馆连接配置文件）、端点和模型、生成参数。跨域转发、原样地址、附加参数收在「高级选项」里。
- **上下文**：读多少条对话记录、是否带角色卡和变量状态、记忆扩展、世界书范围。
- **人格**：说话人格与自定义人格。
- **提示词**：见下一节。
- **界面**：窗口配色、快捷回复栏的「故事神谕」按钮、聊天栏 🌙 按钮等。

### 修改提示词

在设置的「提示词」页，先点分组（普通聊天、剧情参谋、主聊天注入、下一拍建议、上下文段落、人格、内置破限），再点条目。每条都写着这段文字什么时候发、给谁看；点开后在下方编辑。

- 改过的条目和分组都会标出来，点「↺ 恢复默认」回到内置版本。没改过的条目以后会跟着扩展更新自动改进。
- 带变量的条目，编辑区下面列出能用的变量，点一下就插入到光标处。写法是 `{%变量名%}`：
  - 一行里的变量都为空时，这一行会整行省略（比如「切入：{%seed%}」，没有切入点就不出现这一行）；
  - `{%#变量名%}…{%/变量名%}` 只在变量非空时保留中间这段，`{%^变量名%}…{%/变量名%}` 反之。
  - `{{user}}` 等酒馆宏照常可用。
- 有些条目包含程序要解析的格式（比如 `<StorySequence>` 的格式说明）。删掉了必需的变量或格式字样时，提示行会标红并写明缺了什么。
- 「主聊天注入」组的改动会马上应用到正在进行的引导上；已经用 ✏️ 手改过的拍和方案，仍然用你手改的那份。

### 保留的集成

MVU 变量读取、柏宝书 / 小白X 记忆桥、柚月记忆兼容、其它扩展的世界信息、世界书 EJS 渲染与「自定义」范围、补全预设挑选、内置破限、自定义人格、连接存档、对话导入导出，都与原版一致。

## 更新日志

### 1.3.1（2026-10-25）

- 方案条上新增「暂停 / 继续」：想先跑偏一阵时点暂停，主聊天不再注入剧情导向，也不弹停滞提醒、不出下一拍建议；序列、进度、强度都保留，点继续从当前位置接着引导。
- 剧情导向只在主聊天生成、拼提示词的那一下挂上，拼完立即撤下。MVU 额外模型解析、「重新处理变量」和其它插件的后台生成都不会再带上它（以前副模型看到它，会去勾别的插件留下的「本拍已落」）。

### 1.3.0（2026-10-24）

- 主聊天注入精简成一段「剧情导向」：一句交代（这是 {{user}} 希望的走向，用自己的话写、不要照抄）+ 贯穿设定 + 第几拍 + 目标 / 切入 / 节奏。去掉了「幕后剧情引导」抬头和三条执行要求。
- 「剧情引导指令」和「贯穿设定外壳」两条提示词合并为「剧情导向」外壳和「这一拍的内容」。旧的「贯穿设定外壳」自定义不再使用，它的防抢跑那句已并进新外壳。
- 移除落拍感应：主聊天里不再注入状态协议，回复末尾也不再要求写状态行。旧回复里已有的状态行，在显示和发给模型的提示词里都会被剥掉（存档原文不动）。
- 以前用 ✏️ 手改过的拍，读出时自动去掉旧的抬头和执行要求，其余内容不变。

### 1.2.1（2026-10-23）

- 改了模型（或端点、密钥）之后，存档栏显示「存档名 · 已修改」，下面多一条提示：点「保存到此存档」写回去，点「还原」放弃改动。输入框上方的切换栏用「存档名 *」表示改过没存。
- 改动没保存就切到别的存档时，会先确认一次。
- 从旧版升级时，如果当前连接只比某个存档改了模型，也会认出是在这个存档上改的，可以直接保存回去。
- 「存为新存档」遇到同名存档会先确认再覆盖；覆盖后存档留在原来的位置，不再挪到列表末尾。

### 1.2.0（2026-10-23）

- 输入框上方的快捷回复栏（「柏宝书」那一排）新增「故事神谕」按钮，点一下开 / 关窗口；可在设置的「界面」页关掉。
- 设置「连接」页的存档列表改成浮在上层的弹出框，不再把下面的设置往下挤；顶上加了搜索框，回车选第一个匹配项。点别处或按 Esc 收起。

### 1.1.0（2026-10-23）

- 输入框上方新增模型切换栏：点开列出连接存档，一键切换。
- 设置改成 5 页分页，打开时铺满窗口；连接存档改成一行下拉，点开选哪个就用哪个，也可在列表里删除。
- 提示词改成「分组 → 条目」的列表，每条带一句说明；编辑区可点击插入变量。
- 上下文、人格、界面各页重新排版，长说明改成每个选项下面一行小字。

### 1.0.0（2026-10-23）

- 从原版 1.89.0 精简：只保留普通聊天与剧情参谋（单拍方案、序列引导、落拍感应、下一拍建议）。
- 新增提示词注册表：约 45 条提示词可在设置里逐条修改、恢复默认，带变量说明和格式检查。
- 新增序列的贯穿设定（canon）。
- 修复：模型的思考块没闭合时，后面的 `<StorySequence>` 序列块会被一起剥掉。
- 人格的结构保护改为保护 `<StoryPlan>` / `<StorySequence>`；参谋的戏外提醒与预设身份头补上 `<StorySequence>`。
- 启动时检测原版，避免两者同时运行。
